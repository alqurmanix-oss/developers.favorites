كودان منفصلان: زر يحفظ الصفحة في مكتبة Guest الحالية، وأيقونة عائمة تعرض آخر خمسة محفوظات داخل صفحة موقعك نفسها.

يعمل التكامل داخل إطار AQX مضمّن في الصفحة، ولا يفتح نافذة متصفح أو يحوّل الزائر إلى موقع آخر. يحتفظ رمز جلسة Guest داخل نطاق AQX ولا يُرسل إلى الموقع المضيف. قد يطلب المتصفح إذن الوصول إلى تخزين AQX عند أول استخدام؛ إذا منع المتصفح هذا الوصول فلن ينشئ التكامل مكتبة بديلة.

1. كود زر حفظ الصفحة

ضع الكود في موضع الزر داخل الصفحة. الزر يحفظ رابط الصفحة وعنوانها، ويعرض حركة قلب فقط بعد نجاح الحفظ أو إذا كان الرابط محفوظًا مسبقًا.

<script>
(() => {
  const frame = document.createElement('iframe');
  const url = new URL('https://favorites.alqurmanix.com/guest/embed.html');
  url.searchParams.set('mode', 'save');
  url.searchParams.set('url', window.location.href);
  url.searchParams.set('title', document.title || window.location.hostname);
  frame.title = 'AQX Favorites Save';
  frame.allow = 'storage-access';
  frame.setAttribute('allow', 'storage-access');
  frame.setAttribute('allow-storage-access-by-user-activation', '');
  frame.referrerPolicy = 'no-referrer';
  frame.src = url.toString();
  Object.assign(frame.style, {
    width: '170px', height: '56px', border: '0',
    verticalAlign: 'middle', overflow: 'hidden'
  });
  document.currentScript.parentNode.insertBefore(frame, document.currentScript);
})();
</script>

انسخ الكود كما هو والصقه في موضع ظهور زر الحفظ؛ يُنشئ الإطار ويقرأ رابط الصفحة وعنوانها تلقائيًا دون استبدال أي قيم.

2. كود أيقونة المحفوظات العائمة

أيقونة على يسار الصفحة. عند الضغط تفتح لوحة صغيرة داخل الموقع المضيف تعرض أحدث خمسة عناصر فعلية من مكتبة Guest نفسها، مع رابط لفتح المكتبة الكاملة.

<script>
(() => {
  if (document.getElementById('aqx-favorites-recent-frame')) return;
  const frame = document.createElement('iframe');
  frame.id = 'aqx-favorites-recent-frame';
  frame.title = 'AQX Favorites Recent Items';
  frame.allow = 'storage-access';
  frame.referrerPolicy = 'no-referrer';
  Object.assign(frame.style, {
    position: 'fixed', left: '12px', top: '50%',
    transform: 'translateY(-50%)', width: '58px', height: '58px',
    border: '0', zIndex: '2147483000', background: 'transparent'
  });
  frame.src = 'https://favorites.alqurmanix.com/guest/embed.html?mode=recent';
  window.addEventListener('message', event => {
    if (event.origin !== 'https://favorites.alqurmanix.com' ||
        event.source !== frame.contentWindow ||
        !event.data || event.data.type !== 'aqx-favorites-embed-resize') return;
    if (event.data.open) {
      frame.style.width = '380px';
      frame.style.height = '560px';
    } else {
      frame.style.width = '58px';
      frame.style.height = '58px';
    }
  });
  document.body.appendChild(frame);
})();
</script>

اللوحة تظهر داخل إطار مضمّن في الصفحة المضيفة؛ لا تُفتح نافذة متصفح منبثقة ولا يحدث تحويل للزائر.
